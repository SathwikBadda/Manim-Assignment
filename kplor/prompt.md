#  Nano Banana Image Generation Prompts  
### Optimized for K-12 Animated Educational Videos

These prompts are designed to:

-  Avoid photorealism  
-  Keep the subject centered  
-  Use flat 2D vector illustration style  
-  Include a solid, uniform colored background (non-transparent)  
-  Ensure background can be easily removed later  
-  Exclude text, symbols, typography, watermarks, and logos  
-  Maintain a child-friendly educational visual style  

---

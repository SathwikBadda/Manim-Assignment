Step 1: Biological Evolution — From Human to Bird

The collection begins with biological forms. The **Human** figure is a minimalist stick figure constructed from geometric primitives: a circle for the head and lines for the torso, arms, and legs. It is designed to be a generic representation of humanity, capable of basic posing.

The **Bird** is a stylized representation using simple shapes. Its body is an ellipse, with arcs forming flapping wings. A small circle forms the head, and a polygon creates the beak. This design emphasizes motion and flight through the curvature of the wings.

Step 2: Land Transport — Two Wheels and Four

The evolution of transport starts with the **Bicycle**, featuring two spoked wheels, a diamond frame made of lines, and handlebars. It represents human-powered travel.

This evolves into the **Motorcycle**, which shares the two-wheel structure but adds bulk with a fuel tank, engine block (with cooling fins), and a thicker exhaust pipe. The wheels are thicker, and the frame is more robust, signifying powered transport.

The **Car** represents a leap to enclosed, four-wheeled travel. It is built from a rounded rectangle chassis, a polygon roof, and window shapes. Simple circular wheels ground the vehicle, while the body color and window tint add realism.

Step 3: Water Transport — Surface and Depths

The **Boat** is a simple sailboat with a trapezoidal hull, a vertical mast, and a triangular sail. It represents early wind-powered navigation.

The **Ship** is a larger, industrial vessel. It features a two-tone hull (red waterline, dark top), a cabin structure with windows, and stacked colorful containers, symbolizing global trade and cargo transport.

The **Submarine** takes transport underwater. Its elongated elliptical body is topped with a conning tower and periscope. Portholes and a rear propeller add functional details, while the yellow color gives it a classic, recognizable look.

Step 4: Air Transport — Taking Flight

The **WrightPlane** captures the dawn of aviation. It is a biplane structure with two main wings connected by vertical struts. A forward elevator and rear rudder provide control surfaces, resembling the original Flyer design.

The **Airplane** represents a classic biplane or early monoplane era, with a distinct fuselage, top and bottom wings, and a propeller. It bridges the gap between the first flight and modern aviation.

The **Jet** represents modern, high-speed flight. It features a sleek, streamlined fuselage, swept-back wings, and wing-mounted engines. A pointed nose cone and cockpit canopy complete the aerodynamic profile, emphasizing speed and stealth.

Step 5: Code Implementation — Logic and Animation

Each asset is implemented as a Python class inheriting from `manim.VGroup`, ensuring they are easy to instantiate and animate.

1.  **Component Access**: Each class (`Human`, `Bicycle`, `Motorcycle`, `Car`, `Boat`, `Ship`, `Submarine`, `Bird`, `WrightPlane`, `Airplane`, `Jet`) includes a `get_subcomponent` method. This allows you to retrieve specific parts like `front_wheel`, `left_wing`, `engine`, or `head` by name.

    ```python
    def get_subcomponent(self, part_name: str):
        if hasattr(self, part_name):
            return getattr(self, part_name)
        raise ValueError(f"Part name {part_name} not found in [ClassName]")
    ```

2.  **Strict Structure**: visual parts are created in `_build_parts` and added to the `VGroup`. This ensures that `self.submobjects` contains all drawing elements in the correct z-order.

3.  **Animation Integration**: While some classes share a generic `animate_manipulation` method (like `Jet`), others can easily be extended to support it. This helper enables standard Manim animations on specific subcomponents.

    ```python
    def animate_manipulation(self, part_name: str, animation_type: str = "Indicate", **kwargs):
        component = self.get_subcomponent(part_name)
        if not component: return Wait(0.1)
        if animation_type == "Indicate":
            return Indicate(component, **kwargs)
        # ...
    ```

This distinct separation of visual construction and access logic allows for complex storytelling, where a bicycle can transform into a motorcycle, or a bird can fly alongside a jet, all within the same Manim scene.

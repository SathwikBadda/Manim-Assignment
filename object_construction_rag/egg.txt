Egg Asset Collection: A detailed breakdown of the `Egg`, `EggShells`, and `Chicken` assets, describing their visual construction and code implementation.
--------------------------------------------------------------------------------------------------

Step 1: The Egg — Origin and Simplicity

The **Egg** is constructed as a simple, elegant form. Its body is a vertically oriented ellipse, elongated to resemble a typical egg shape. It is filled with an off-white color (`#FFFEF7`) and outlined in a soft gray-brown (`#D4C5B9`) to suggest fragility.

To create volume, a subtle highlight is added. This is a smaller, semi-transparent white ellipse positioned off-center near the top, simulating light reflection on a smooth, curved surface. This minimal detail transforms a flat shape into a 3D-looking object.

Step 2: The Shells — Breaking and Hatching

When the egg cracks, it splits into **EggShells**. This asset consists of two distinct parts: a **top shell** and a **bottom shell**.

Both shells are derived from the original egg shape but are cut open with jagged lines. The top shell is a dome with a zig-zag bottom edge, while the bottom shell is a cup with a matching zig-zag top edge. An inner darker outline (`#FFF8E7`) emphasizes the thickness of the shell at the break line, adding realism to the fracture.

Step 3: The Chicken — Life Emerges

From the broken shells emerges the **Chicken**. This character is built from a hierarchy of circles and ellipses.

-   **Body & Head**: Two yellow circles stacked vertically form the base.
-   **Tuft**: Three small circles on top of the head create a fluffy crest.
-   **Wings**: Darker yellow ellipses, rotated slightly, form the wings on either side.
-   **Face**: The face features detailed eyes (white sclera, black pupil, white shine), an orange triangular beak, and pink blush marks on the cheeks for a cute, appealing look.
-   **Feet**: Orange polygons at the bottom represent webbed feet.

The layering order ensures that the beak, eyes, and blush sit on top of the head, while the wings and feet are correctly positioned relative to the body.

Step 4: Code Implementation — Logic and Animation

The visual designs are encapsulated in Python classes: `Egg`, `EggShells`, and `Chicken`, all inheriting from `manim.VGroup`.

1.  **Component Access**: Each class provides a `get_subcomponent` method to access individual parts.
    -   `Egg`: `body`, `highlight`
    -   `EggShells`: `top_shell`, `top_inner`, `bottom_shell`, `bottom_inner`
    -   `Chicken`: `head`, `body`, `left_wing`, `right_wing`, `beak`, `left_eye`, `right_eye`, etc.

    ```python
    def get_subcomponent(self, part_name: str):
        if hasattr(self, part_name):
            return getattr(self, part_name)
        raise ValueError(f"Part name {part_name} not found in [ClassName]")
    ```

2.  **Dynamic Coloring**: The `set_color` method allows for runtime color changes. Crucially, it respects the specific opacity settings of different parts (e.g., maintaining the semi-transparent blush on the chicken or the highlight on the egg).

    ```python
    def set_color(self, part_name: str, color: str):
        component = self.get_subcomponent(part_name)
        if component:
            c = ManimColor(color)
            if isinstance(component, VMobject):
                component.set_color(c)
                if component.get_fill_opacity() > 0:
                     opacity = 0.3 if "highlight" in part_name else 1
                     component.set_fill(c, opacity=opacity)
    ```
